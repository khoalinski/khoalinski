I'm a Software Engineering honors student at RMIT University Vietnam (GPA: 3.6) with a deep focus on **Full-Stack and Front-End Web Development**. I am passionate about building accessible, data-driven FinTech products and highly responsive interfaces using React, Next.js, JavaScript, and TypeScript. 

Beyond coursework, I am an active Technology Department Member at the RMIT FinTech Club and Neo Culture Tech, where I enjoy collaborating on award-winning projects[cite: 7]. I also have a growing interest in Artificial Intelligence and how it can be integrated with modern front-end architectures.

### 🚀 What I'm Currently Working On

*   **FinRecruit:** Serving as the primary Front-end Engineer for a recruitment management dashboard. I engineered a role-based UI using Next.js, TypeScript, and TSX, and optimized state management with custom React hooks for real-time data tracking.
*   **Relievo:** Developing the responsive, accessible interface for a full-stack MERN food redistribution platform. I am implementing modular UI components with Tailwind CSS that strictly adhere to Nielsen's 10 Usability Heuristics and WCAG AA standards.
